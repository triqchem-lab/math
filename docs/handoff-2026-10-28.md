## 二、口径（必须保留的措辞）

1. **全枚举 ≠ 归纳证明**：覆盖同态 576 对、49 对特征标正交、24² δ 正交、729 点纤维分布
   都是**有限集全枚举**；引用时写"全枚举"，不写"已证明"。
2. **P1（891）**：`135×12 − 729 = 891` 只是**两个描述的差**；"891 = 扭转类大小"**不成立**。
3. **P2（Hopf）**：A₄ 作用有 27 个固定点 ⇒ 是**分层商**，不是主丛/纤维丛；
   "无等变截面"是固定点的直接推论，不是拓扑障碍。
4. **P7（G0/G1）**：只是方向标签，本库不约定坐标系，"顺时针/逆时针"没有可检验定义。
5. **Soliton 近似**：Q32/Q16 整数配方与实数 `sin²` 的一致性由 oracle 回执
   `ba93f0e3…`（≤1 Q16-ulp）承载，**不是**内核证明。
6. **NSE 三模式并存**：PumpA/PumpB 是两种历史启发式，mode 2 是形式化 `nsStep`；
   这是**人类裁决的兼容策略**，不是"三选一"。

## 五、ABI 1.1 的语义边界（易踩）

| 项 | 规定 |
|---|---|
| 元素编码 | A₄ 元素 = `0..11`（Id=0，Rot(i,j)=1+2i+j，Flip(k)=9+k）；矩阵 = 4 个 GF(3) 分量行主序 |
| 非 SL 矩阵 | `sov_sl23_inv/pow/order`、`sov_cover_perm` 要求 det = 1，否则 `SOV_ERR_RANGE` |
| 元素阶 | `sov_a4_order` 只可能返回 1/2/3；`sov_sl23_order` 返回 1..6 |
| 旋量相位 | `sov_spin_phase_act` 的 `k` 任意 `uint32`，语义为 α^(k mod 4) |
| 纤维分布 | `sov_hopf_fiber_distribution` 固定 4 组 `(size,count)`，顺序按 size 升序 |
| 特征标 | 输出 `(re, im)` 表示 `re + im·ω`；正交结果应为实部 24 或 12 |
| 越界 | 点 `≥ 729` → −2；元素 `≥ 12` → −2；irrep `≥ 4` / class `≥ 7` / row `≥ 7` → −2 |
