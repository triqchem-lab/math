## 四、⚠ 数字根形式化的陈旧状态（本轮确认）

`Sovereign/Foundation/DigitalRoot.agda` 长期未更新，现状非常薄：

```agda
digitalRoot : ℕ → ℕ
digitalRoot n = n % 9

digitalRootMod9 : ∀ n → digitalRoot n ≡ n % 9
digitalRootMod9 n = refl
```

- 只有「模 9」语义，**没有**经典数字根（1..9 循环）的定义与定理；
- 没有 `dr(dr n) ≡ dr n`（幂等）、`dr(n+9) ≡ dr n`（周期）等常用性质的形式化（`DigitalRootCycle.agda` 也只围绕 `% 9`）；
- 与 ABI 的经典实现**不同函数**，已在契约 §17 显式区分；
- 结论：这是**形式化侧的欠账**，不是 ABI 的错。升级路线（未做）：
  1. 在 Agda 加 `classicRoot : ℕ → ℕ`（`0 ↦ 0`，`n>0 ↦ 1 + (n−1) % 9`）；
  2. 证 `classicRoot n ≡ if n % 9 == 0 ∧ n > 0 then 9 else n % 9`；
  3. 证幂等/周期/加法同态，并与 `digitalRoot`（mod 9）建立精确关系；
  4. 届时 ABI 两版函数都能与形式化逐点对齐。
